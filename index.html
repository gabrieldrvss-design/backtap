Privacy Policy

This privacy policy applies to the BackTap app (hereby referred to as "Application") for mobile devices, created by Gabriel31 (hereby referred to as "Service Provider") as a Commercial service. This service is intended for use "AS IS".

What information does the Application obtain and how is it used?

The Application does not collect, transmit, or store personal identifying information (such as your name, email address, or phone number) when you download and use it. Registration is not required to use the Application.

User Feedback and Rating Submissions

The Application includes an optional in-app feedback feature allowing users to submit ratings and suggestions for app updates. When you choose to submit feedback, the Application securely transmits the following non-personal data to Google Cloud Firestore via Firebase Anonymous Authentication:

  • Your star rating (1 to 5) and optional written suggestion.
  • App version and build number.
  • Device manufacturer and model (e.g., to debug device-specific gesture detection).
  • Android OS / SDK version and timestamp.
  • An anonymous, randomly generated user identifier to manage review submissions.

This feedback data is used exclusively to evaluate and improve gesture detection algorithms and app performance. Feedback submissions are stored securely and are not sold or shared with third-party advertisers.

Analytics and Performance

The Application uses Google Firebase Analytics to collect aggregated, anonymous usage and diagnostics metrics (such as gesture trigger events, detector model types, and general app interactions). This information helps the Service Provider identify bugs, optimize sensor performance across different hardware manufacturers, and enhance user experience. Firebase Analytics does not collect personal identifying information.

Accessibility Service Usage

To function, the Application uses Android Accessibility Service access. This is required to detect configured back tap gestures and perform user-selected actions such as Back, Home, Recents, Notifications, Quick Settings, Screenshot, Assistant, Flashlight toggling, or launching selected apps.

If enabled by the user, the Application also uses Accessibility features to detect contextual conditions such as the currently active app and whether the keyboard is visible so that blocking and context rules can work correctly. All accessibility-related processing stays strictly on your device. No accessibility data, screen content, typed text, or app usage data is collected, stored remotely, or transmitted by the Service Provider.

Sensor and Device State Access

The Application uses device sensors and system state information, including accelerometer, gyroscope, proximity sensor, screen state, lock state, charging state, headset connection state, audio playback state, and call state, in order to detect back tap gestures and apply user-configured conditions or protections.

This processing is performed only on the device. No raw sensor data or device state data is uploaded, shared, or stored externally.

Installed Apps and App Selection

The Application uses the list of installed launchable apps only to allow the user to select apps for actions such as launching an app or blocking gestures in specific apps. This information is used solely for on-device app selection and local preference storage.

No installed app list is transmitted, sold, or shared with third parties.

Settings Storage

The Application stores user preferences locally on the device, such as selected actions, sensitivity level, blocked apps, and setup state. These settings are stored only to provide Application functionality and personalization.

These settings remain on your device and are not transmitted to the Service Provider.

Does the Application collect precise real-time location information?

This Application does not collect precise information about the location of your mobile device.

Advertising and Third-Party Services

The Application uses third-party services provided by Google LLC, which may collect data in accordance with their respective privacy policies:

  • Google AdMob & User Messaging Platform (UMP): May collect advertising identifiers, device info, and usage metrics to serve and measure ads and manage user consent choices.
  • Google Firebase (Analytics, Authentication & Cloud Firestore): For aggregated usage analytics and hosting optional user feedback submissions.

You can opt out of personalized advertising through your device's ad settings (Settings → Google → Ads → Opt out of Ads Personalization) or within the in-app Privacy Options form.

For more information on how Google uses data, see: https://policies.google.com/technologies/partner-sites

Do third parties see and/or have access to information obtained by the Application?

Aside from the Google services described above (AdMob and Firebase Analytics / Firestore for optional feedback), the Application does not collect personal information, and no other data handled by the Application is shared with third parties.

What are my opt-out rights?

You can stop the Application's functionality at any time by:

  • Disabling the Accessibility Service for the Application in Android settings.
  • Turning off gesture detection inside the Application settings.
  • Uninstalling the Application.

Children

The Application is not used to knowingly solicit data from or market to children under the age of 13. The Service Provider does not knowingly collect personally identifiable information from children.

Security

The Service Provider is committed to safeguarding user privacy. All network communications with Firebase and Google services are encrypted in transit using industry-standard HTTPS/TLS protocols.

Changes

This Privacy Policy may be updated from time to time. The Service Provider will notify you of any changes by updating this page.
